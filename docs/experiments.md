# Experiment log

Record each experiment with:

- Experiment ID and question.
- Dataset manifest hash and corpus split.
- Model configuration and random seed.
- Training steps, optimizer and learning-rate schedule.
- Training and validation loss.
- Checkpoint identifier.
- Fixed prompts, sampling parameters and generated samples.
- Hardware, elapsed time and throughput.

Change one major variable at a time when comparing configurations. Keep generated artifacts out of Git unless they are small, non-sensitive and intentionally selected for documentation.
